# WolbaCaspian

WolbaCaspian is a network of low-cost, solar-powered environmental monitoring stations for the Caspian lowlands of Azerbaijan (Lankaran, Astara, Masallı region). Each station logs air temperature, water temperature, humidity, rainfall and standing water every 15 minutes. The readings are turned into a transparent estimate of mosquito **breeding-habitat suitability**, so that ditches, containers and tyres can be drained, covered or removed where conditions are most favourable. It does not release mosquitoes or _Wolbachia_, diagnose disease or predict outbreaks. Developed by Jeyla Ahmadzada, Ilyas Taghiyev, Youssef El Haroun, Mikayil Ahmadbayli and Vahid Musayev.
